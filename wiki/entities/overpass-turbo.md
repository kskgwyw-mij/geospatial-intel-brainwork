Web-based IDE for writing and visualising Overpass API queries; the thesis names it as the way to define which OSM objects count.

- The thesis scope is "Overpass Turbo existent objects" ([[thesis-goal]]).
- Overpass Turbo exports results as GeoJSON, KML or GPX, and the same queries can be scripted directly against the [[overpass-api]]. (unsourced)
- Practical role: prototype and document the per-class queries (for example buildings, solar panels, swimming pools) in Turbo, then automate them with the API for dataset building. (unsourced)

The full menu of queryable objects is in [[osm-object-catalog]].
